# Kanade

Android向けのローカル音楽プレイヤーです。端末内の音楽ファイルを、ハイレゾのまま高音質で再生することを目指しています。

> 開発中です。以下は目標とする機能で、まだ実装されていないものを含みます。

## 主な機能

- **ハイレゾ再生**: FLAC・ALAC・WAVなどのロスレス音源を、24bit/32bit・高サンプルレートのまま出力
- **USB DACへのビットパーフェクト出力**: Android 14以降の対応端末で、音源のデータを加工せずにUSB DACへ送る
- **イコライザー**: グラフィックEQ、プリセット、プリアンプ、Bass/Treble、リミッター
- **ライブラリ**: アルバム、アーティスト、フォルダー、ジャンルでの閲覧と検索
- **プレイリスト**: 作成・編集、ソート、ドラッグでの並べ替え、複数曲のまとめて移動、元に戻す
- **再生キュー**: 「次に再生」「キューに追加」、キュー内の並べ替え
- **再生**: ギャップレス再生、シャッフル、リピート、バックグラウンド再生、通知・ロック画面・Bluetoothからの操作

## 対応環境

- Android 12 (API 31) ~ Android 17 (API 37)

## 技術スタック

Kotlin / Jetpack Compose / AndroidX Media3 (ExoPlayer) / Room / Hilt
