# Kanade

Android向けのローカル音楽プレイヤーです。端末内の音楽ファイルを再生します。

## 主な機能

- **ライブラリ**: すべての曲・アルバム・アーティスト・フォルダ・ジャンル・プレイリストから探す (アーティストはアルバムの一覧から曲へ)。最近追加した曲・最近再生した曲・よく再生する曲、検索。画面下のメニューから、どの画面でもライブラリ・イコライザー・検索・再生キューへ移れる
- **複数選択**: 曲・アルバム・アーティスト・プレイリストなどを長押しで選び、まとめて再生・追加する。複数のプレイリストも続けて再生できる
- **スキャン対象のフォルダ**: 読み込むフォルダを選べる (内部ストレージ・SDカード、初期値は「Music」と「Movies」)。最初の起動で自動で読み込み、あとは右上の︙の「再スキャン」で読み直す。対象から外した曲は、プレイリストに残ったまま再生では飛ばす
- **再生**: ギャップレス再生、シャッフル、リピート、スリープタイマー、再生速度の変更。通知・ロック画面・Bluetoothからの操作
- **動画**: 端末内の動画も、音楽と同じライブラリ・再生キュー・イコライザーで再生する。バックグラウンドでは音声だけで再生を続ける
- **再生キュー**: 「次に再生」「キューに追加」、キュー内の並べ替え
- **プレイリスト**: 作成・編集、ドラッグでの並べ替え、まとめて移動、元に戻す、重複の確認 (アーティスト・曲名・長さが同じ曲)
- **イコライザー**: 10バンド、プリセット、プリアンプ、低音・高音、リミッター。出力先ごとに設定を分けられる
- **音量と左右**: バランス、モノラル、ReplayGain
- **出力**: 24bit・32bitの音源はそのままの精度で出力。Android 14以降はUSB DACへのビットパーフェクト出力
- **歌詞**: 曲に埋め込まれた歌詞の表示 (時刻付きは今の行を追いかける)
- **バックアップ**: 設定・EQのプリセット・プレイリストの書き出しと復元
- **ファイラーから開く**: ファイラーの「このアプリで開く」で渡された音声・動画ファイルを、ライブラリに入れずにそのまま再生

## 対応環境

- Android 7.0 (API 24) ~ Android 17 (API 37)

## インストール

[Releases](../../releases)からAPKをダウンロードして、端末で開きます。提供元不明のアプリのインストールを許可する必要があります。

## ビルド

FLACのデコーダー (libFLAC) はgitのサブモジュールで、NDKでビルドします。クローンするときはサブモジュールも取ってきます。

```
git clone --recurse-submodules https://github.com/malvaceae/kanade.git
./gradlew :app:assembleDebug
```

すでにクローンしてある場合は、`git submodule update --init`でサブモジュールを取ってきます。

リリース版を署名してビルドするには、`~/.gradle/gradle.properties`に鍵の場所とパスワードを書きます (リポジトリには入れません)。

```
kanade.release.storeFile=C:/path/to/kanade-release.jks
kanade.release.keyAlias=kanade
kanade.release.storePassword=...
```

書かれていない場合、リリース版は署名せずにビルドします。
